# سامانه هوشمند تغذیه دانشگاه علوم پزشکی اصفهان (MUI SFD)

اپلیکیشن اندروید اختصاصی برای اتوماسیون تغذیه و رزرو غذای دانشجویان دانشگاه علوم پزشکی و خدمات بهداشتی درمانی اصفهان (سامانه کالینان).

## امکانات

- 🔐 **ورود خودکار و سریع**: با حل خودکار کپچا (OCR هوشمند درون‌برنامه‌ای) و حفظ سشن.
- 🍱 **مشاهده و رزرو غذا**: نمایش منوی هفتگی، روزها و وضعیت رزرو سلف دانشجویی.
- ⚡ **رزرو خودکار هوشمند**: رزرو طبق سلیقه کاربر با بررسی هوشمند؛ چنانچه کاربر قبلاً در یک هفته دستی غذا رزرو کرده باشد، رزرو خودکار جهت احترام به انتخاب‌های کاربر اجرا نمی‌شود.
- 🌐 **پورتال وب درون‌برنامه‌ای**: حل اطلاعیه‌ها و پیام‌های سیستمی کالینان مستقیماً درون اپلیکیشن همراه با همگام‌سازی سشن.
- 💳 **شارژ کیف پول**: پرداخت مستقیم از طریق درگاه‌های بانکی شاپرک.
- 📢 **سیستم تبلیغات و بروزرسانی**: اتصال به یکتانت و کنترل از راه دور نسخه و اطلاعیه‌ها از طریق GitHub.
